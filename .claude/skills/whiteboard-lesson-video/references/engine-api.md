# エンジン API（assets/engine.js）

lesson.js は engine.js と同じ範囲に入れてビルドされるので、ここにある関数・定数は import なしでそのまま使える。

## 目次
1. 画面と座標
2. シーンとステップ（SCENE_LIST と startLesson）

## 1. 画面と座標
- 論理サイズ 1080×1350（縦 4:5）。左上が (0,0)、下向きが +y。点は `[x, y]`。
- 置き場所（重ならないように）

| 場所 | y | だれが描くか |
|---|---|---|
| タイトル | 108（ふりがなは 77 あたり） | エンジン（scene.title） |
| 凡例 | 172 | エンジン（legend: true のシーン） |
| 図 | 200〜960 | lesson.js |
| 字幕 | 980〜1115（2行: 1022 / 1094） | エンジン（beat.cap） |
| 下の数式 | 1192（分数は ±60） | エンジン（beat.f） |
| 下の帯 | 1255〜1350 | 経過時間の表示。何も置かない |

- 左右は x = 60〜1020 に収める。図のいちばん下の文字は y 960 まで（字幕のふりがなとぶつかるため）。
- 1cm を何 px にするかは図ごとに決めて定数にする（見本：三角形 120px/cm、地図 32px/cm、方眼紙 64px/cm、実景 44px/m）。

## 2. シーンとステップ
```js
const SCENE_LIST = [
  { title: '{縮尺|しゅくしゃく}を{分数|ぶんすう}と{比|ひ}で{表|あらわ}す',  // 上に字間を広げて出る
    legend: true,            // 凡例を出すか
    dur: 33,                 // シーンの長さ（秒）
    draw: drawS1,            // draw(lt)：lt はシーン内の経過秒（0〜dur）
    beats: [                 // ステップ＝字幕と下の数式の単位。「ステップで止める」もここで止まる
      { t: 0,    cd: .8, cap: '1行目\n2行目', f: 's1a', fd: 2.8 },
      { t: 5.5,  cap: '…', f: 's1b', fd: .6 },
      { t: 43.5, cap: '…', f: 's3h', fd: .6, ul: [6, 7, 4.0, 4.8] }
    ] }
];
startLesson({
  scenes: SCENE_LIST,
  forms: FORMS,                                   // 下の数式 { キー: (p) => トークン配列 }
  legend: [{ c: 'map', label: '{縮図|しゅくず}の{長|なが}さ' }, { c: 'real', label: '{実際|じっさい}の{長|なが}さ' }],
  poster: 7.3                                     // 「動きを減らす」設定の端末で最初に止めて見せる秒
});
```
- beat の項目：`t` 開始秒（シーン内）、`cap` 字幕（`\n` で2行）、`cd` 字幕が出るまでの秒（既定 .15）、`f` 下の数式のキー（null で無し）、`fd` 数式が出るまでの秒（既定 .3）、`ul: [i0, i1, t0, t1]` 下の数式のトークン i0〜i1 に答えの下線を、ステップ開始から t0〜t1 秒で引く。
- 次のステップでも同じ `f` なら、数式は消えずにそのまま残る。
- ステップの終わり（次の beat の t、または dur）が「ステップで止める」の停止位置。シーンとシーンの間は 0.8 秒のフェード（自動。startLesson の `gap` で変更可）。
- `forms[key](p)`：p はステップ開始からの秒（消えていく途中は 99）。p を使えば1組ずつ出せる（見本 `FORMS.pairs`）。
- lesson.js では名前を `FORMS`, `SCENE_LIST` にする（エンジン内部の FORM, SCENES と重ならないように）。

## 3. 時間と動き
- `S(t, a, b)` … t が a→b の間に 0→1（なめらか）。出る・動くの基本。`seg(t, a, b)` は等速。
- `eo(x)` 最後がゆっくり、`eio(x)` 両端がゆっくり、`eback(x)` 少し行きすぎて戻る（点が「ポン」と出る）。
- `lerp(a, b, t)`、`lp(p, q, t)`（点の補間）、`clamp01(x)`、`DEG`（度→ラジアン）。
- `NOW` … 全体の経過秒。止まらずに続く小さな動き（視線の点線が流れる等）にだけ使う。
- **draw(lt) は lt だけで絵が決まるように書く。** Math.random や、前のフレームの状態を使わない（動画の書き出しは同じ時刻を何度でも描くため）。
- 例：`const a = S(lt, 2.0, 2.6) * (1 - S(lt, 11.5, 12.0));` … 2.0〜2.6秒で出て、11.5〜12.0秒で消える。

## 4. 図をかく関数
共通：`c` 色名か `[r,g,b]`、`al` 不透明度、`p` 0〜1 の進み具合、`w` 線の太さ。

| 関数 | 用途 |
|---|---|
| `line(a, b, p, c, w, al, {dash, flow, glow, cap})` | 線分（p で途中まで）。`dash:[10,8]` 破線、`flow: NOW*20` で点線が流れる |
| `poly(pts, p, c, w, al, opt)` | 折れ線を長さの割合 p まで（図形を「かいていく」） |
| `fillPoly(pts, c, al)` | ぬりつぶし（al .06〜.1 で薄く） |
| `dot(p, r, c, al, glow)` ／ `ring(p, r, c, al, w)` | 点 ／ 輪（交点のパルスなど） |
| `arrow(a, b, p, c, w, al, head)` | 矢印 |
| `dimV(x, y0, y1, p, c, al)` ／ `dimH(y, x0, x1, p, c, al)` | 寸法線（両矢印） |
| `tickV(p, len, c, al)` | 短い縦の目盛り |
| `grid(x0, y0, x1, y1, step, al)` | 方眼（al .06〜.08） |
| `rightMark(p0, dA, dB, s, al, c)` | 直角のしるし（dA, dB は2辺の向きの単位ベクトル） |
| `angleArc(c, r, a0, a1, p, col, al, w)` | 角の弧（ラジアン。上向きはマイナス：`-50*DEG`） |
| `handCircle(cx, cy, rx, ry, p, c, al, w)` | 先生が単位を丸でかこむような手書き風の丸 |
| `answerLine(x0, x1, y, p, c, al)` | 答えの下線と「//」（板書のまね） |
| `rulerH(x0, y, len, cm, al)` ／ `rulerV(x, y0, len, cm, al)` | ものさし（mm 目盛り付き） |
| `protractor(c, r, al)` ／ `setSquare(q, dx, al)` | 分度器 ／ 三角定規 |
| `alongPath(pts, f)` | 折れ線の長さの割合 f の位置（1つの点を道にそって動かす） |
| `qtyLayout(num, unit, cx, cy, size)` → `drawQty(q, c, al, glow)` | 「4 cm」などの数と単位。`q.ux` `q.wu` で単位の位置がわかる（丸でかこむとき） |
| `numC(s, cx, cy, size, c, al)` ／ `opC(s, …)` | 数字 ／ 演算子を1つ置く（飛んでいく数字などに） |

- 一部分だけ縮小・移動するとき（見本の「実景を左上に小さく」）は `ctx.save(); ctx.translate(ox, oy); ctx.scale(k, k); … ctx.restore();`
- `ctx` はそのまま使えるが、状態は必ず save/restore で戻す。

## 5. 文字
- `text(s, x, y, font, c, al, align, base, glow)`：align は 'center' | 'left' | 'right'。y は文字の中心。
- フォント：`fJ(size, weight)` 日本語（300 細い／400／500 やや太い）、`fM(size)` 数字・単位、`fI(size)` 点の名前（イタリックの A, B, A′）。
- ふりがな：`'{縮図|しゅくず}の{長|なが}さ'` → 漢字の上にかな（大きさ 50%）。熟語はまとめる。かなが長いときは、となりのかなの上に少しはみ出す（となりもふりがなのときは間をあける。自動）。
- 記号：`'$A′$'` → 数式のイタリックで描く（日本語フォントに ′ がないため）。字幕の中でも使える。
- `twidth(s, font)`：ふりがな込みの幅。`spaced(s, x, y, font, spacing, c, al)`：字間を広げた文字（タイトル用）。

## 6. 数式トークン
`formula(toks, cx, yc, size, al)` → `{ x0, x1, boxes }`（中央そろえ）。`formulaL(toks, x, yc, size, al)` は左そろえ。`layoutF(toks, cx, size)` は描かずに位置だけ。

| トークン | 意味 | 例 |
|---|---|---|
| `n(s, c, opt)` | 数字（かっこも） | `n('10000', 'real')` |
| `u(s, c, opt)` | 単位（前に少し空き） | `u('cm')` |
| `op(s, opt)` | 演算子（前後に空き） | `op('=')` `op('÷')` `op('×')` `op(':')` |
| `j(s, c, opt)` | 日本語（ふりがな可） | `j('{縮尺|しゅくしゃく}')` |
| `v(s, c, opt)` | イタリックの記号 | `v('A′', 'map')` |
| `fr(num, den, opt)` | 分数（分子・分母はトークン配列） | `fr([n('1')], [n('2500')])` |
| `ar(dir, w, opt)` | 矢印 'r' 'l' 'lr'（`lab` で上に文字） | `ar('r', 1.9, { lab: '×100' })` |
| `sp(w)` | 空白（文字の大きさに対する割合） | `sp(1.1)` |

- opt：`a` 不透明度（0 にすると場所だけ取って見えない＝あとから出す部分に使う）、`g` 光、`st` 0〜1 で数字に斜線（先生の「0を消す」）、`z` 大きさの比（j, fr）。
- `boxes[i].x0 / x1` で i 番目のトークンの左右がわかる → 答えの下線、2行目の「＝」をそろえる（見本 drawS2 の 12000 cm → 120 m）。

## 7. 色
- `RGB`：`w`（白）, `red`, `blue`, `green`, `amber`, `violet`。lesson.js の最初で意味の名前を付ける：
  `Object.assign(RGB, { map: RGB.red, real: RGB.blue });`
- `col(c, a)` → rgba 文字列、`mixRGB(a, b, t)` → 2色の途中（青から赤に変わりながら動く点など）。

## 8. 見本のどこを見ればよいか（lessons/shukuzu/lesson.js）
| やりたいこと | 見本 |
|---|---|
| 頂点を1つずつ対応させる（A→A′）、下に対応の一覧 | `drawIntro`、`FORMS.pairs` |
| 対応する辺を1組ずつ光らせる | `drawIntro` の後半 |
| 数字が飛んで分数になる → 約分 → 比に変形 | `drawS1`（b3〜b4） |
| 単位を丸でかこんで ×100 | `drawS1`（b2）、`drawS2`（b2） |
| 区切って数える（1cm＝25m を4回） | `drawS1`（b5） |
| 地図（方眼）と縮尺のバッジ | `drawS2`（b1） |
| 長い線が縮んで縮図の長さに ／ のびて実際の長さに | `drawS2`（b3 ／ b4） |
| 0を3こずつ消すわり算、2行目の「＝」をそろえる | `drawS2`（b3 ／ b4） |
| 実景を左上に小さく → 方眼紙で作図 | `drawS3`、`drawPaper` |
| ものさし・分度器・三角定規・ものさしで測る | `drawPaper` |
| 作図した三角形を実景にもどす | `drawPaper` の最後（mp） |
| 足りない長さ（目の高さ）をたす | `drawRealScene` の最後（b8） |

## 9. プレーヤーと書き出し
- 自動で付くもの：再生・一時停止、前後のステップ（← →）、速さ（0.75／1／1.25）、ステップで止める（S キー）、シーンの区切り付きの進行バー、ライト／ダーク表示、動きを減らす設定への対応、公開ページで埋め込みフォントが使えないときの読み直し。
- `?export=1` を付けて開くと操作部を隠し 1080×1350 に固定。`window.__lesson`（total, pauses, nav, scenes, render(t), ready）を lesson.py が使う。
- build のとき、フォントは使っている文字だけに絞って埋め込む（HTML 1ファイルでオフラインでも表示できる）。
