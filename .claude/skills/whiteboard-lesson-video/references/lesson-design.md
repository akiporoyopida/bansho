## 1. 構成の型
- **導入**（10〜12秒、1〜2ステップ）：単元の考え方を1枚の絵で。問題の数字はまだ使わない。
- **問題ごとに1シーン**（25〜50秒、4〜8ステップ）：先生の解き方の順番どおりに進める。
- **まとめ**（10〜12秒）：きまり（公式）と、まちがえやすい点を1つ。
- 全体 2〜3 分。長くなるときはシーンを分けるか、ステップを減らす。

## 2. ステップの作り方
- 1ステップ＝1つの考え。「単位をそろえる」「分数にする」「約分する」は別のステップにする。
- ステップごとに決めること
  - 字幕：何をしているか、なぜそうするか
  - 図の動き：それが目で見てわかる形
  - 下の数式：そのステップの計算、または使っているきまり
- 中央で計算そのものを大きく見せるとき（約分、0を消すわり算）は、下の数式は「きまり」にする。中央が絵のときは、下に計算を出す。同じものを2か所に出さない。
- 答えが出るステップでは、答えに下線「//」を引く。
- 測って求める値（作図して定規ではかる等）は「約」をつける。

## 3. 字幕の書き方
- 2行まで、1行 22 字くらい。読点のところで自然に改行する。
- 板書・教科書と同じ言葉を使う（縮尺、実際の長さ、縮図上の長さ …）。
- 分数は「10000分の4」のように読める形で書く。長い計算式は字幕に全部書かず、数式で見せる。

## 4. ふりがなと言葉
- 画面に出る漢字にはすべてふりがなを付ける（タイトル、凡例、図のラベル、下の数式の日本語も）。
- 熟語はまとめて付ける：`{縮図上|しゅくずじょう}`、`{直角三角形|ちょっかくさんかくけい}`。
- 読みに注意：交わる（まじわる）、2本（ほん）、〜分の1（ぶん）、かけ算・わり算（ざん）。迷う読みは notes.md に書いてユーザーに確認する。
- 点の名前は `$A$`、`$A′$`（エーダッシュ）。教科書に合わせて D・E・F のような別の文字を使ってほしいと言われることもある。

## 5. 確認リスト（shots の一覧で、ステップごとに）

- [ ] 図が y 960 より下に出ていない（字幕とぶつからない）

## 6. これまでの失敗と直し方
| 起きたこと | 直し方 |
|---|---|
| 導入で、頂点の数より多い点が流れ続け、どの頂点がどこへ行くのかわからない（ユーザーからの指摘） | 動く点は1つだけ。A→A′、B→B′、C→C′ の順に1つずつ動かし、行き先に名前、下の数式に対応の一覧 |
| 分数と分数の間の「＝」が片方に寄る | 左右の分数の幅を見て、真ん中に置く |
| 図のいちばん下のラベル（10 m）と字幕が近い | 図は y 960 まで。寸法線を地面に近づける |
| 「駅」のふりがなが点に重なる | ふりがなの分も考えて、点からラベルまで 50px 以上はなす |
| 「縮図 上」「直角 三角形」の間があく | 熟語はまとめてふりがなを付ける |
| ≈ が表示されない | 「約」と書く |
| 字幕の ′ が別の字体になる | `$A′$` と書いて数式の字体にする |
| スマホで操作ボタンが数式に重なる | ボタンは図の外に置く（テンプレートで対応済み） |
| 公開ページで埋め込みフォントが使えないことがある | 同じ書体を自動で読み直す（エンジンで対応済み） |
