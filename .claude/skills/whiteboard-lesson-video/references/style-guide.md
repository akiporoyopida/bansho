# 見た目と動きのルール

もとにしたのは、黒い背景に細い白線と光る点がゆっくり動き、上に字間の広い小さな見出し、下にセリフ体の数式がある、数学解説の縦長ショート動画。**静かに、1つずつ、はっきり。**

## 色
- 背景は真っ黒 #000。図形の線は白（不透明度 .85）、補助線は白 .22〜.26 の破線、方眼は .07。
- 意味のある色は2色まで（`RGB.red` #FF7B72 ／ `RGB.blue` #86A8FF）。レッスンの最初に意味を決めて凡例に出し、最後まで変えない。
  - 見本：縮図の長さ＝赤、実際の長さ＝青（先生の赤ペン・青ペンに合わせた）。
  - ほかの単元の例：わかっている数＝青・求める答え＝赤 ／ もとにする量＝青・くらべる量＝赤。
- 3色目（green, amber, violet）は本当に必要なときだけ。
- 光（glow）は「今見てほしいもの」だけ。強調 8〜16、ふだんは 5〜10。

## 文字
| 役割 | 書き方 | 大きさ |
|---|---|---|
| タイトル | scene.title（細字・字間広め。自動） | 38 |
| 字幕 | beat.cap（自動） | 40、2行まで |
| 図のラベル（日本語） | `fJ(size, 500)` | 26〜32 |
| 図の数と単位 | `qtyLayout` + `drawQty` | 34〜48、主役は 64〜80 |
| 点の名前 | `fI(size)` | 36〜42 |
| 下の数式 | beat.f（自動） | 52 |
- ふりがなは漢字の 50%（自動）。24 より小さい日本語は使わない（ふりがなが読めなくなる）。

## 線
- 図形 2〜2.4、主役の辺 2.8〜3.4（glow 6〜10）、補助線 1.2〜1.6、寸法線 1.8。

## 動き
- 基本は `S()`（ゆっくり出てゆっくり止まる）。出る 0.4〜0.6 秒、線をかいていく 0.8〜1.4 秒、移動 0.8〜1.2 秒。
- 同時に出すものは 0.2〜0.4 秒ずつずらす。
- 1ステップ 5.5〜8 秒。動きはステップが終わる 1.5 秒前までに終える（止めて見せる絵になるため）。
- 止まらずに続く動きは控えめに（見上げる線の点線が流れる、点がゆっくり光る程度）。**粒をたくさん流し続ける表現はしない。**
- 対応や順番を見せるときは、1つずつ・同じ速さで動かし、行き先に名前を付ける。
- 「前 → 後」がつながって見えるように動かす：数字は飛んで移動、分数は比に変形、線は縮む・のびる。消して出し直すより、動かしてつなぐ。

## 先生の板書とつなげる目じるし
- 単位を丸でかこむ（`handCircle`）→ 矢印 → 「×100」。
- 0を斜線で消す（数式トークンの `st`）。
- 答えの下線と「//」（`answerLine`、下の数式なら beat の `ul`）。
- 分数の横に小さく「縮図」「実際」（先生の 小・大 の書きこみにあたる）。

## 画面の組み立て
- 1ステップで目立たせる変化は1つ。それ以外は不透明度 .38〜.4 に暗くするか、小さくして端へよせる。
- 前のステップの答えは消さずに小さく残すと、つながりがわかる（見本：1 : 2500 を下に小さく残す）。
- 場面が大きく変わるとき（実景 → 方眼紙の作図）は、前の絵を左上に小さく残す（縮小 .38 と細い枠）。
- ラベルは点・線から 20〜30px はなす。ふりがな付きのラベルは、上にふりがなの分（文字の大きさの半分くらい）もあける。

## しないこと
- 3行以上の字幕、長すぎる1行（22字くらいをこえると自動で小さくなる）。
- ≈ などフォントにない文字、ふりがなのない漢字（build が警告する）。
- 意味のない飾りの動き、途中で色の意味を変えること。
