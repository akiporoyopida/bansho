## 2. 読み取り
### (1) グラフが点(−2, 2)を通り、直線 y＝x−6 と x軸上の点で交わる
- 先生の解き方：y＝0 のときの座標 (6, 0) → y＝ax＋b にこの2点を代入 → {−2a＋b＝2, 6a＋b＝0}（連立方程式）→ a＝−1/4、b＝3/2
- 答え：y＝−1/4 x＋3/2（下線と「//」）
### (2) グラフが2直線 y＝1/2 x、y＝−2x＋5 の交点を通り、直線 y＝3x−1 に平行
- 先生の解き方：連立方程式を解く → 交点(2, 1) → 代入 y＝3x＋b → b＝−5
- 答え：y＝3x−5

## 3. 検算
- (1) 0＝x−6 → x＝6。2式をひくと −8a＝2 → a＝−1/4、b＝6/4＝3/2。(−2, 2)：1/2＋3/2＝2 ✓
- (2) x/2＝−2x＋5 → x＝2、y＝1 ✓。1＝6＋b → b＝−5 ✓

## 6. 注意すること
- 平行 → 傾きが同じ。切片は代入で求める。
- 字幕の分数は「4分の1」のように読む形。マイナスは「−」（全角の－はフォントにない）。

## 7. QAメモ
- ステップで止めた画面で、0＝x−6 の計算と(2)の連立方程式が消えていた → ステップの終わりまで残す。
- y 軸の「y」が凡例とぶつかった → y を軸の右に置き、平面を少し下げた。
- (6, 0) のラベルが目もりの 6 と直線に重なった → 左上へ。
- 「連立方程式」の小さなラベルが式に重なった → けした（字幕で言う）。
- 直線の式のラベルが、動く赤い直線と重なった → 平面の外（上・左）へ。
