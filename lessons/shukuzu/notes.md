# 縮図の利用・縮尺（lessons/shukuzu）

完成例。板書2枚 → 約2分23秒（導入 11.8秒＋問題3つ＋まとめ）。

## 1. 元の板書
- `source/board-problems.png` … 問題だけの板書
- `source/board-solutions.png` … 同じ板書に先生の解き方と答えが書きこまれたもの

## 2. 読み取り
### 問題1（直角三角形 ABC。C が左上、A が左下の直角、B が右下）
- 問題文：AB の実際の長さ 100m を 4cm で表しています。① 縮尺を分数で表すと？ ② 縮尺を比で表すと？
- 先生の解き方：100m＝10000cm にそろえる → 4/10000（分子に「小」、分母に「大」と書きこみ）→ ÷4 で約分 → 1/2500 → 1：2500
- 答え：① 1/2500 ② 1：2500
- 目じるし：m を丸でかこむ、答えに下線と「//」

### 問題2（ゼブラさんの家のまわりの 4000分の1 の縮図。学校・家・駅）
- 問題文：③ 家から学校までの実際の道のりは 800m。縮図では何 cm？ ④ 縮図で家から駅は 3cm。実際は何 m？
- 先生の解き方：③ 800m＝80000cm、80000÷4000 は 0 を3こずつ斜線で消して 20cm ④ 3×4000＝12000cm＝120m
- 答え：③ 20cm ④ 120m

### 問題3（校舎の高さ）
- 問題文：目の高さ 1.4m、校舎から 10m はなれて、てっぺんを見上げた角度は 50°。200分の1 の縮図をかいて校舎の高さを求める。
- 先生の解き方：10m＝1000cm、1000÷200＝5cm の底辺 → 分度器で 50°、直角に線 → 縦は約 6cm → 6×200＝1200cm＝12m → 12＋1.4＝13.4m
- 答え：約 13.4m

## 3. 検算
- ① 4/10000＝1/2500 ✓ ② 1：2500 ✓ ③ 80000÷4000＝20 ✓ ④ 3×4000＝12000cm＝120m ✓
- 問題3：5×tan50°＝5.96cm → 約 6cm ✓（12m＋1.4m＝13.4m、「約」を付ける）

## 4. 色の意味
- 赤（`RGB.red` → `map`）：縮図の長さ（先生の赤ペン）
- 青（`RGB.blue` → `real`）：実際の長さ（先生の青ペン）

## 6. 注意すること
- 単位をそろえてから比べる（m → cm）。
- 問題3の三角形は「目の高さから上」だけ。最後に 1.4m をたすのを忘れない。
- 地図は縮尺どおり（1cm＝32px、学校〜家 20cm＝640px）。

## 7. QAメモ
- 導入の点が多すぎて対応がわからない → 1つずつ動かす形に作り直した。
- 「＝」の位置、10m のラベルと字幕の間、駅のふりがなと点の重なりを直した。
- ふりがなを全部の漢字に付け、熟語はまとめた。字幕の A′ は数式の字体にした。
