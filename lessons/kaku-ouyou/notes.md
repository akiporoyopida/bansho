# 対頂角・同位角・錯角（応用編）（lessons/kaku-ouyou）

## 1. 元の板書
- source/board3-problems.png … 問題だけ（数学「対頂角・同位角・錯角 ③・応用編」）
- source/board3-solutions.png … 同じ板書に先生の解き方（赤・青ペン、補助の平行線に矢印）

## 2. 読み取り
問題文：ℓ//m のとき、∠x、∠y の大きさをもとめよう！
### ①（折れ線の頂点が1つ）
- 与えられた角：頂点の角 112°、m と折れ線の角 130°（m の下・右）。x は ℓ の上・左。
- 先生の解き方：130° → m の上の角 50°。頂点を通る平行線（矢印）→ 下の部分 50°、上の部分 62° → x＝62°
- 答え：x＝62°（下線 //）
### ②（長方形 ABCD を図のように折った）
- 与えられた角：64°（折り目の点で、AD と折った辺の間）
- 先生の解き方：116°（＝180−64）、x＝116÷2＝58°。AD//BC（矢印）、Z の形。y＝64＋58＝122°
- 答え：x＝58°、y＝122°（下線 //）。板書に折り目の点の名前はない → 動画では E（AD 上）、F（BC 上）と名前を付けて字幕で説明
### ③（折れ線の頂点が2つ）
- 与えられた角：51°（ℓ の下・左）、79°（下の頂点）、27°（m の下・左）
- 先生の解き方：2つの頂点に平行線（矢印）。27° → 下の頂点の下の部分 27°、79−27＝52°、錯角で上の頂点の下の部分 52°、51° も錯角で上の部分 51° → x＝51＋52＝103°
- 答え：x＝103°（下線 //）

## 3. 検算
- ① 180−130＝50。頂点の下の部分は錯角で 50、112−50＝62。x は頂点の上の部分と同位角（同じ直線・同じ位置）で 62 ✓
- ② 折り返した2つの角＋64＝180 → 58＋58＋64＝180 ✓。∠BFE は ∠DEF（64＋58＝122）の錯角 ✓。y＝∠BFE を折り返した角＝122 ✓
- ③ 27°の対頂角と下の頂点の下の部分は錯角（＝同位角として一度で説明）27、79−27＝52 ✓、錯角 52、錯角 51、51＋52＝103 ✓
- 図はすべて実際の角度で作図（lesson.js の meet / at で座標を計算）

## 4. 色の意味
- 青（given）：わかっている角（問題に出てくる角）
- 赤（answer）：求める角（x, y）
- 途中で求めた角（50°, 62°, 116°, 58°, 122°, 27°, 52°, 51°）は白

## 6. 注意すること
- 折れ線の角は「頂点を通る平行線」で2つに分けてから考える。
- 折り返した角は等しい（②の x と、y）。
- 錯角は交わる線にそって角を移しながら向きを 180° 回して見せる（中点まわりに回すと図の外へ飛ぶため）。

## 7. QAメモ
- ② y の答え「122°」が折った紙の辺に重なった → y の右へ移動。
- ③ 答え「103°」が破線に重なった → 黒い下地をしいた。
- まとめで、図の文字と下の数式が同じ内容だった → 下の数式をなくした。まとめの左の図が画面の端にはみ出した → 図を2段に並べ直した。
