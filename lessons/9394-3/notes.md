## 2. 読み取り（大問3）
- 問題文：直線m の式は y＝2x＋b、直線n の式は y＝−x＋10。点P は2直線の交点。A・B はそれぞれ直線m・n と x軸との交点で、A の x座標は −2。
- (1) b の値：A(−2, 0) → y＝2x＋b へ代入、2×(−2)＋b＝0、b＝4
- (2) △ABP の面積（1目もり1cm）：{y＝2x＋4, y＝−x＋10} を解いて P(2, 8)（高さ＝8）。直線n の式から B(10, 0)。A(−2,0) から B(10,0) までの長さ AB＝12。12×8×½＝48cm²
- (3) P を通り△ABP の面積を2等分する直線：底辺AB を2等分する座標を通る。AB＝12 の½は6。(4, 0)。P(2, 8) と (4, 0) を通る直線は y＝−4x＋16
- 目じるし：答えに下線と「//」、「底辺」「高さ」の書きこみ、図に「高さ」「底辺」の点線

## 3. 検算
- (1) −4＋b＝0 → b＝4 ✓
- (2) 2x＋4＝−x＋10 → x＝2, y＝8 ✓ ／ 0＝−x＋10 → x＝10 ✓ ／ 10−(−2)＝12 ✓ ／ 12×8÷2＝48 ✓
- (3) (−2＋10)÷2＝4 ✓ ／ 傾き (0−8)÷(4−2)＝−4、0＝−16＋b → b＝16 ✓ ／ 左右の三角形 6×8÷2＝24 ずつ ✓

## 6. 注意すること
- 右上（x 5.5〜11, y 6〜10）が空いているので、計算はそこに黒い下地をしいて出す。
- 座標のラベルは、x軸の下で直線と重ならないように点の左へずらす。
- エンジンの定数 `H`（画面の高さ）と名前がぶつかるので、高さの足は `HF`。
- 板書の (3) は「P(2,8) と (4,0) を通る直線は y＝−4x＋16」まで。傾きと切片の出し方は動画で足した。

## 7. QAメモ
- `H` の二重定義でページが動かなかった → `HF` に。
- 座標ラベル (−2,0)・(10,0)・(4,0) に直線が重なる → 点の左下へ。
- P の座標と「+2」の矢印が重なる → P の座標を右上、「+2」を矢印の下へ。「−8」が直線n に重なる → 下へ。
- 左の「24 cm²」が y軸の目もりに重なる → 位置と大きさを変えた。
- (2) の最後で右上の計算と下の数式が同じだった → 下は「面積＝底辺×高さ×½」のきまりに。
