## 2. 読み取り
### 問1（2本の直線に1本の直線が交わる図。2本は平行ではない）
- 上の交点：a 左上、d 右上、b 左下、c 右下 ／ 下の交点：e 左上、h 右上、f 左下、g 右下
- ① ∠b の対頂角は ∠d ② ∠e の対頂角は ∠g
- ③ ∠d の同位角は ∠h ④ ∠f の同位角は ∠b（先生は d・h の横に赤で「右上」と書きこみ）
- ⑤ ∠a の錯角は ∠g ⑥ ∠h の錯角は ∠b
### 問2（ℓ//m、交わる直線と 30°）
- 30° は ℓ との交点の左下（ℓ の左と、交わる直線の左下向きの間）
- ⑦ 30°（対頂角） ⑧ 180−30＝150° ⑨ 30°（錯角。先生は Z の形を横にかき、ℓ//m を青い丸でかこむ）
- 答えに赤の下線と「//」

## 3. 検算
- ①〜④、⑥：位置から確認 ✓
- ⑤：∠a と ∠g は2本の直線の外側どうし。教科書によっては錯角を内側の組（∠b と ∠h、∠c と ∠e）だけにしている。
  → 2026-09-30 にユーザーに確認し、**板書どおり ∠g** で作ると決めた。
- ⑦ 対頂角 30° ✓ ⑨ 錯角（Z）30° ✓ ⑧ 一直線 180−30＝150° ✓

## 4. 色の意味（3本とも同じ）
- 青（`given`）：わかっている角（問題に出てくる角）
- 赤（`answer`）：求める角（先生の赤ペン）
- 白く光る線：その関係を作っている線（X・Zの形、一直線など）。平行のしるしは「>」

## 6. 注意すること
- 問1の2本は平行ではないので、同位角・錯角を「重ねて」見せない（大きさがちがう）。位置だけを見せる。
- 問2（平行）では、重ねて等しいことを見せる。
- ∠ は日本語フォント、ℓ は数式フォントにしかない：字幕は `∠$x$`、`$ℓ$`、下の数式は `ANG('x')`、`v('ℓ')`。全角の「－」はフォントにないので「−」。
