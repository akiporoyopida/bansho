# 動く点と三角形の面積（lessons/9394-2）

## 1. 元の板書
- source/board-p93-answers.png … 印刷の問題（No.14・15）に先生の手書きの解答。この動画は No.14 の大問2だけ。

## 2. 読み取り
- 問題文：∠B＝90°の直角三角形ABC で、点PはAを出発して、辺上をBを通ってCまで動く。PがAから x cm 動いたときの△APCの面積を y cm² とする。
- 図：AB＝4cm、BC＝3cm（A 左下、B 右下、C 右上）
- (1) PがAB上：y＝x（底辺）×3（高さ）×½ → y＝3/2 x
- (2) PがBC上：y＝(4＋3−x)（底辺）×4（高さ）×½ → y＝−2x＋14
- (3) グラフ：(0,0)→(4,6)→(7,0) の折れ線（印刷の図にかきこみ）
- 目じるし：式の下に「三角形の面積」「底辺」「高さ」の書きこみ、答えに下線「//」

## 3. 検算
- (1) △APC の底辺 AP＝x、高さ BC＝3 → y＝3x/2 ✓（x＝4 で 6）
- (2) PC＝7−x、高さ（Aから直線BCまで）＝AB＝4 → y＝2(7−x)＝−2x＋14 ✓（x＝4 で 6、x＝7 で 0）
- (3) 2つの式が x＝4 で y＝6 につながる ✓

## 4. 色の意味（9394-1〜4 共通）
- 青（given）：わかっている点・式（この動画ではわかっている長さ 4cm・3cm、底辺・高さ）
- 赤（answer）：求める式・答え（面積 y、△APC のぬり、グラフ）

## 6. 注意すること
- (2) の高さは AB（A から直線BC までのきょり）。底辺は PC＝4＋3−x（板書どおりの書き方を残す）。
- 「≦」は使わず「xが0から4」と書く。

## 7. QAメモ
- (1) の最後で、中央の計算と下の数式が同じ（x＝4 → y＝6）だった → 下は y＝3/2x を残す。
- (3) の最後で、字幕は「PがBにあるとき」なのに図の P が C にあった → P を B に置き直し、△APC とグラフの点 (4,6) を出す。
- 下の数式の下線が「y＝」の下に出ていた → トークンの番号を直した。
- （見直し）(2) で「x cm」が AB の下だけにあり AB＝x と誤解しやすい → 「AB＋BP＝x cm」に。
