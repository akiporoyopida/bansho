## 2. 読み取り
- ① 左の直線：ℓとの交点の左下が70°、mとの交点の右上が∠x。右の直線：mとの交点の左上が55°、ℓとの交点の右上が∠y。
  先生：70°（左下）→ 同位角で m の左下も70° → 対頂角で x＝70°。55°（左上）→ 同位角で ℓ の左上も55° → y＝180−55＝125°。
- ② 2本の直線が ℓ 上の1点で交わる。上の角 80°、∠x は ℓ の左側。右の直線と m の左上が41°、左の直線と m の左上が ∠y。
  先生：x＝41°（左上どうしの同位角）、y＝41＋80＝121°（左上どうしの同位角）。
- ③ 3本の直線が1点で交わる。76°（横の直線の左・上）、23°（右・上）、∠y（右・下）、∠x（下のまん中）。
  先生：x＝180−99＝81°、y＝76°。
- ④ 折れ線。ℓとの交点の右下が137°、mとの交点の左上が29°、頂点の角が ∠x。
  先生：180−137＝43°、頂点を通る平行線をひく、錯角で43°と29° → x＝43＋29＝72°。

## 3. 検算
- ① 錯角でも x＝70° ✓。y：ℓ の左上 55° → 180−55＝125 ✓
- ② x：41° ✓。上の左上の角＝x＋80＝121 ✓
- ③ 上半分 76＋?＋23＝180 → ?＝81、x はその対頂角 81 ✓、y は 76 の対頂角 ✓
- ④ 180−137＝43、43＋29＝72 ✓
- 図は実際の角度で作図（meet() で交点を計算）。

## 4. 色の意味
- 青（given）：わかっている角（問題の角と、とちゅうでわかった角）
- 赤（answer）：求める角 ∠x、∠y

## 6. 注意すること
- ②の ∠y は「x＋80」の角の同位角。上の点の左上全体を大きな弧で見せる。
- ④の補助線は破線、ℓ・m と同じ「>」を付ける。錯角は線にそって移す（中点まわりに回すと図の外へ飛ぶ）。

## 7. QAメモ
- ②の 121° と「左上」が重なった → 位置を分けた。x の 41° を x のとなりへ。
- ④の最後 72° が 43°/29° とぶつかる → 最後のステップで 43°/29° のラベルを消し、72° を x のとなりに。
- （まとめ）見出しの点に凡例の青・赤を使っていて色の意味がずれていた → 白に。左によっていたので中央へ、字幕と同じ内容の下の数式は消した。
